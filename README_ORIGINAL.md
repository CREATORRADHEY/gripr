# GRIPR — Build for Bharat. For the World.

**GRIPR** is a high-signal demand capture engine designed to bridge the gap between real Indian frustrations and global builders. It captures anonymous, multi-lingual feedback from across Bharat and ranks it by real market demand.

---

## 🚀 Live Production
- **URL:** [https://gripr.studio](https://gripr.studio)
- **Deployment:** Vercel (Production)

## ✨ Core Features
- **Multi-Lingual Funnel:** Captures problems in Hindi, Hinglish, and 7+ regional languages.
- **Institutional Design:** A premium, high-conversion "Cream/Dark" aesthetic designed for institutional trust.
- **Demand Intelligence:** AI-ready clustering of user frustrations to provide ranked "Builder Signals."
- **Automated Lead Capture:** Integrated with Google Sheets and Google Apps Script for seamless automation.

## 🛠️ Technology Stack
- **Frontend:** Vanilla HTML5, CSS3 (Custom Design System), JavaScript.
- **Backend/CRM:** Google Apps Script / Google Sheets.
- **Hosting:** Vercel.
- **Typography:** DM Serif Display, Space Grotesk, DM Sans.
